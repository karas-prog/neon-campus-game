# NEON CAMPUS

Браузерная игра-квест по университетскому кампусу.

## Level 01 — Коридор

Первый уровень воспроизводит логику корпуса: длинный светлый коридор, окна по внешней стороне справа, кабинеты вдоль внутренней стены слева и лестница в конце крыла.

## Запуск локально

Откройте `index.html` в браузере. Версия автономна: внешние библиотеки не требуются.

## Управление

- `W` / `S` — движение вперёд и назад
- `A` / `D` или `←` / `→` — поворот
- `E` — взаимодействие с терминалом
- `Пробел` — сканировать цифровые помехи

## Публикация

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## План развития

- Реальная 3D-сцена на Babylon.js с GLB-моделями корпуса
- Атриум, лестницы и четыре этажа
- Звук, сохранение прогресса и результаты для преподавателя
- Интеграция результатов с LMS/Google Sheets
